# 架构说明

## 产品闭环

```text
考试档案
  └─ 考点树（权重 / 掌握度）
       ├─ 错题（关联考点）
       │    └─ 复习项（到期时间 / 间隔 / 难度）
       │         └─ 复习记录（评分 / 用时）
       └─ 上岸指数 = Σ(权重 × 掌握度) / Σ(权重)
```

Ashore 的核心不是“记录了多少”，而是让每个考点都有可解释的掌握度，并让错题按间隔回到复习队列。

## 分层与依赖方向

```text
src/core        纯 TypeScript：类型、SM-2 调度、掌握度、日期、导入解析
src/data        Dexie 表结构、事务仓库、示例数据、备份恢复
src/hooks       useLiveQuery 查询封装、主题应用
src/stores      主题 / 当前考试偏好
src/ui          设计系统与通用组件
src/features    Today / Syllabus / Mistakes / Review / Insights / Settings / Shell
```

约束：

- `core` 不依赖 React、Dexie、浏览器 API，便于单测与未来复用。
- `data` 依赖 `core`，对外暴露仓库函数，不暴露 Dexie 细节。
- `features` 通过 hooks 订阅数据，写操作调用仓库函数。
- `ui` 不保存业务数据，只处理展示与可访问性。

## 数据流

1. 页面通过 `useLiveQuery` 订阅 Dexie 查询。
2. 写操作在 `src/data/repo.ts` 中以事务执行，保证多表一致。
3. Dexie 通知订阅者，页面自动刷新。
4. 复习评分事务同时更新：复习项、复习记录、关联考点的掌握度。

## 调度器

v0.1 使用收敛后的 SM-2：

- 初始 ease `2.5`，范围 `1.3–2.8`。
- 首次「记得」间隔 1 天，「简单」3 天。
- 「忘记」：间隔归零，10 分钟后重新出现，ease 下降，lapses + 1。
- 「困难」：间隔按 1.2 倍增长，ease 下降。
- 「记得」：间隔按 ease 增长。
- 「简单」：间隔按 ease × 1.3 增长，ease 上升。
- 最大间隔 365 天。

选择理由与完整取舍见 [ADR 0002](adr/0002-sm2-scheduler.md)。

## 掌握度与上岸指数

考点掌握度是一个 `0–1` 的值：

- 新建错题会让关联考点掌握度轻微下降（-0.04）。
- 复习评分会微调掌握度：忘记 -0.12、困难 -0.05、记得 +0.06、简单 +0.12。
- 用户可以在考点编辑框中手动调整掌握度，作为算法之外的校准。

上岸指数：

```text
readiness = Σ(weight_i × mastery_i) / Σ(weight_i)
```

覆盖率默认以 `mastery >= 0.5` 计为已覆盖。薄弱考点按掌握度升序、权重降序排序。

## 本地优先

- 数据存在 IndexedDB，刷新、离线、重新安装 PWA 后仍在（除非浏览器清理站点数据）。
- 无账号、无服务端、无遥测。
- 备份格式为带 `schemaVersion` 的 JSON，导入前显示数据摘要并要求输入确认文字。
- iOS 会回收长期未使用的 PWA 存储，因此界面会提醒定期导出备份。

## 双端与桌面壳

v0.1 是响应式 PWA：

- 桌面：左侧栏 + 内容区。
- 移动端：顶部栏 + 底部五个主导航 + 安全区适配。
- 对话框在移动端自动变为底部抽屉。

v0.2 计划用 Tauri 2 包装同一份前端产物，使用系统 WebView，避免 Electron 的体积。应用商店原生包不在 v0.1 范围内。

## 性能预算

| 项目          | 预算                   |
| ------------- | ---------------------- |
| 首屏 JS       | ≤ 180 KB gzip          |
| 全部 JS       | ≤ 260 KB gzip          |
| 首屏 CSS      | ≤ 40 KB gzip           |
| 全部 CSS      | ≤ 60 KB gzip           |
| PWA 缓存      | ≤ 2 MB（不含用户图片） |
| 10,000 条错题 | 列表虚拟化后再评估     |

不使用组件库、图表库和中文 Web 字体；图表由 SVG/CSS 自绘，图标为内联 SVG，字体使用系统栈。

## 可访问性与体验

- 所有主要操作可键盘完成；复习页支持空格翻面、`1–4` 评分。
- 对话框包含焦点陷阱、Esc 关闭、关闭后焦点返回触发元素。
- 移动端触控目标不小于 44px，底部导航适配 `env(safe-area-inset-bottom)`。
- 尊重 `prefers-reduced-motion`。
- 用户可见错误提供下一步动作；技术细节只写控制台。

## 测试策略

- 单元测试：调度、掌握度、日期、导入解析。
- 数据层测试：使用 `fake-indexeddb` 验证事务、首次评分、错题入队。
- 端到端：Playwright 覆盖“示例数据 → 记录错题 → 复习评分”和“导入大纲”。
- 包体检查：`scripts/check-bundle-size.mjs` 读取 Vite manifest，防止无意膨胀。
- 文件头检查：`scripts/check-headers.mjs` 在 pre-commit 与 CI 中执行。

## 已知限制

- 没有云同步，多设备需要手动导出/导入。
- 错题内容按纯文本渲染，暂不支持 Markdown 渲染。
- 图片先压缩后以 Data URL 存在 IndexedDB，大量图片会占用较多空间。
- 复习调度是简化模型，不包含完整 FSRS 的可提取性拟合。
- 导出/导入会整体替换数据，不支持按考试合并。
